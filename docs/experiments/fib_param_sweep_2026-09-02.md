# Fib Retracement 参数调优实验报告

> **日期**: 2026-09-02  
> **标的**: 885003.WI (沪深300) / 1d  
> **K线数**: 5500 根  
> **最新收盘价**: 5140.28  

---

## 1. 实验目标

通过**单变量逐步调优**，系统性地找到 Fib Retracement 管道中各参数的最优值，最大化三个核心指标：

| 指标 | 定义 | 衡量方式 |
|------|------|----------|
| **覆盖度** | 当前价格附近有多少条有效 Fib 线 | 存活组数 + ±5% 范围内不同价位数 |
| **拟合度** | Fib 网格与聚类点的对齐程度 | 平均 score（越高越好） |
| **可解释性** | Fib 线在后续行情中被价格尊重的程度 | 组寿命 + 失效原因合理性 |

## 2. 实验方法

### 2.1 基线参数

以 fib003（中期配置）作为基线，其余参数固定不变，每轮仅变动一个参数。

```toml

zigzag_thresholds = [0.08, 0.12]

```

### 2.2 实验流程

```
Sweep 1~5: 单变量扫描 (5 个核心参数, 每个 5~7 个梯度)
    ↓
Round 2: 组合优化 (Top 维度最优区间交叉, 8 组)
    ↓
Round 3: 精细微调 (围绕 Top2 组合, 13 组)
    ↓
Round 4: 极致调优 + 三层 pivot 发现 (8 组)
    ↓
Round 5: 三层 pivot 交叉验证 (6 组)
    ↓
最终参数确定 → 正式生成 5 组 profile 数据
```

总计约 **60 组实验**。

## 5. 关键突破：三层 Pivot Window

### 5.1 发现

在 Round 4 中测试添加第三层 pivot window `[5,5]`，结果：

```
两层 pivot [8,8],[13,13]:  avg_score ≈ 1.8
三层 pivot [5,5],[8,8],[13,13]: avg_score ≈ 3.4 ~ 4.4  (+89%~+144%)
```

**原因**: 多尺度 pivot 检测提供更丰富的聚类特征点（小尺度捕捉微结构，大尺度确认主趋势），Fib 网格拟合到更多证据点。

## 9. 经验总结

### 9.1 调参优先级

1. **pivot_windows 层数** — 影响最大，三层是质的飞跃
2. **stale_min_coverage** — 最敏感的连续参数，0.25 是甜点
3. **min_fit_score** — 准入门槛，1.0 宽准入 + stale 淘汰比 1.5 严准入效果更好
4. **recent_bars** — 决定时间层级，80~100 最均衡
5. **boundary_tolerance_k / break_bars** — 影响中等，0.05 + 6 bars 较稳
6. **cluster_tolerance_pct** — 影响最小，0.005~0.006 即可

### 9.2 设计哲学

> **宽准入 + 自然淘汰 > 严准入 + 宽容留存**

- `min_fit_score=1.0`（低门槛）让更多组进入，再通过 `stale` 和 `boundary_break` 自然淘汰不佳的组
- 这比 `min_fit_score=1.5`（高门槛）+ 不淘汰的策略效果更好
- 原因：高 score 不保证后续可解释性，低 score 有时也能长期有效
